# Установка Whisper Studio для человека или агента

Удалённые вычисления с ноутбука на другом компьютере, включая работу через
интернет, описаны в [REMOTE.md](REMOTE.md). Они включаются отдельно и не меняют
обычный локальный запуск.

Публичный репозиторий: https://github.com/romolego/whisper-studio.
Оболочка работает локально на Windows x64. Пользовательские проекты и записи
не входят в репозиторий. Поддерживаются CPU и NVIDIA CUDA; для AMD/Intel GPU
используйте CPU. Интернет нужен при установке программ, зависимостей и моделей.

## Быстрый старт

Скачайте **Code → Download ZIP** и распакуйте, например в `D:\whisper`.
Если установлен Git, можно выполнить:

```powershell
git clone https://github.com/romolego/whisper-studio.git D:\whisper
cd D:\whisper
```

Запустите `Установить Whisper.bat`. Режим `auto` выбирает CUDA, если
`nvidia-smi` обнаружил работающую NVIDIA, иначе CPU. Установщик сам ставит
Python 3.11, Node.js, FFmpeg и PowerShell 7 через `winget`, зависимости,
модели Whisper и Nemotron, а затем проверяет вычисления на выбранном устройстве.
Если `winget` отсутствует, установите «Установщик приложений» Windows из Microsoft
Store либо эти четыре программы вручную. Node.js должен быть не ниже 22.13.
При ошибке повторите установку: существующие модели и рабочие данные сохраняются.

После успешной установки запустите `Запустить Whisper.bat`.
Интерфейс откроется на http://127.0.0.1:3000. Начните с короткой записи.

## Команды для агента

Агенту удобнее вызывать PowerShell-скрипт напрямую: BAT-файл ждёт нажатия клавиши.
Команды выполняются из корня скачанного проекта.

Посмотреть план без установки и изменения настроек:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Plan
```

Только процессор — видеокарта и CUDA не нужны:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Device cpu
```

Автоматический выбор:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Device auto
```

Явно использовать NVIDIA:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Device cuda
```

Установщик требует работающий драйвер NVIDIA: сам драйвер ставится отдельно
с [сайта NVIDIA](https://www.nvidia.com/Download/index.aspx).
Он скачивает DLL cuBLAS/cuDNN из официальных NVIDIA-колёс на PyPI в
`vendor/cuda/bin` и ставит CUDA-версию PyTorch в `.venv_diarization_gpu`.
Полный CUDA Toolkit отдельно ставить не требуется для этой схемы установки.

По умолчанию используется PyTorch 2.11.0 с CUDA 12.6; для NVIDIA с compute
capability 10 или новее автоматически выбирается CUDA 12.8.
Вариант можно указать явно, например для RTX 50 / Blackwell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Device cuda -CudaVariant cu128
```

Режим `cuda` сообщает об ошибке, если NVIDIA или проверка вычислений недоступны.
Агент должен устранить ошибку драйвера/сборки, а не объявлять CPU ускорением GPU.
Не все старые видеокарты поддерживаются; поддержка проверяется по архитектуре
PyTorch и настоящим вычислениям. В `auto` Whisper может вернуться на CPU при
ошибке GPU во время работы; выбранное устройство показывается в результате.

## Модели и режим работы

На CPU и GPU используются одинаковые модели:

| Назначение | Модель | Закреплённая ревизия |
| --- | --- | --- |
| Русская расшифровка | `coriollon/whisper-large-v3-turbo-russian`, `ct2_int8_float16` | `1158957eaa77976d79e1d2e6083a55826931c37f` |
| Английская и автоматическое определение языка | `mobiuslabsgmbh/faster-whisper-large-v3-turbo` | `0a363e9161cbc7ed1431c9597a8ceaf0c4f78fcf` |
| Разметка спикеров | `nvidia/Nemotron-3-Diarization` | `f667ed73aee57d40cc39428eb768b4fd87a0a29e` |

Это ревизии исходной рабочей установки. Whisper скачивается в `models`,
Nemotron — в пользовательский кеш Hugging Face. Токен для этих моделей не нужен.
В новой пустой установке движком спикеров выбирается Nemotron. Настройки уже
существующей установки сохраняются, кроме явно запрошенной смены устройства.
При переключении режима установки перезапустите сервис.

CPU-среда разметки находится в `.venv_diarization_cpu`, GPU-среда — в
`.venv_diarization_gpu`. Настройка Whisper записывается в `data/runtime.json`,
настройка устройства спикеров — в локальную базу. В CPU-режиме Whisper использует
`int8`, а процессы спикеров получают CPU-среду в приоритетном порядке.
CPU обрабатывает те же записи, но обычно медленнее GPU; длительность зависит
от процессора и записи. Начните с короткого примера, затем пробуйте длинные файлы.

Pyannote доступен как дополнительный движок. Для него нужно принять условия
[модели](https://huggingface.co/pyannote/speaker-diarization-community-1) и ввести
личный токен Hugging Face в «Настройки → Спикеры». Для начала с Nemotron это
не требуется. Токены, проекты, модели и аппаратные среды не публикуются в Git.

## Проверка результата

Установщик возвращает ненулевой код, если обязательный этап завершился ошибкой.
Он проверяет CTranslate2 на выбранном устройстве и матричный расчёт PyTorch
в отдельной среде разметки. Это проверка библиотек, а не готовой расшифровки.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1 -NoBrowser
.\.venv\Scripts\python.exe -m scripts.doctor
```

Откройте интерфейс, загрузите короткую аудиозапись и проверьте непустой текст,
разметку спикеров Nemotron и фактическое устройство. Пользовательских записей
в репозитории нет. Для замера скорости положите свою короткую русскую WAV-запись
в `data/test-ru.wav` и повторите `scripts.doctor`.

Агент должен сообщить: выбранный режим, установленные версии, доступность моделей,
адрес интерфейса, результат проверки вычислений и результат пробной расшифровки.
Если аудиозапись не предоставлена, прямо указать, что распознавание не проверено.

Готовый запрос агенту:

> Установи https://github.com/romolego/whisper-studio на этом компьютере.
> Прочитай AGENTS.md и INSTALL.md. Сначала покажи план установки. Используй CPU,
> если NVIDIA недоступна; если NVIDIA есть, настрой ускорение. Скачай закреплённые
> модели Whisper и Nemotron, запусти интерфейс и проверь вычисления. Для пробной
> расшифровки используй запись, которую я предоставлю. Сообщи реальные результаты
> и фактическое устройство.

Дополнительные ключи `-SkipFrontend` и `-SkipDiarization` нужны для частичной
установки и отладки. Они не являются полной установкой студии с Nemotron.
Подробности резервной копии и восстановления — в [RESTORE.md](RESTORE.md).
