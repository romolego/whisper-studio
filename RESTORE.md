# Восстановление Whisper Studio

Резервная копия кода: https://github.com/romolego/whisper-studio (закрытый репозиторий).
Для скачивания нужно войти в GitHub под аккаунтом с доступом к репозиторию.
Копия предназначена для восстановления оболочки с пустым списком проектов.

## После потери диска или на другом компьютере

1. Откройте репозиторий и нажмите **Code → Download ZIP**. Распакуйте архив,
   например в `D:\whisper`. Можно использовать любой диск; прежний `E:` не нужен.
   Для первого запуска лучше выбрать путь без пробелов.
2. Запустите `Установить Whisper.bat`. Нужен интернет и Windows x64.
   Установщик использует `winget` из приложения «Установщик приложений» Windows.
   Если `winget` отсутствует, установите его из Microsoft Store или вручную
   установите Python 3.11, Node.js 22.13 или новее, FFmpeg и PowerShell 7.
3. Дождитесь установки Python-пакетов, сборки интерфейса и загрузки моделей.
   После обрыва сети повторно запустите тот же установщик: он продолжит установку.
4. Запустите `Запустить Whisper.bat`. Откроется http://127.0.0.1:3000.
   Рабочие папки и пустая база проектов создаются автоматически.
5. В настройках проверьте «Модели и зависимости» и «Спикеры».
   Если модель Whisper не докачалась, используйте загрузку моделей в настройках
   или повторите установку. Затем расшифруйте короткую запись для проверки.

## Какие модели скачиваются

| Назначение | Источник | Как восстановить |
| --- | --- | --- |
| Русский Whisper Turbo | [coriollon/whisper-large-v3-turbo-russian](https://huggingface.co/coriollon/whisper-large-v3-turbo-russian) | Установщик скачивает `ct2_int8_float16` в `models/turbo-russian` |
| Английский Whisper Turbo | [mobiuslabsgmbh/faster-whisper-large-v3-turbo](https://huggingface.co/mobiuslabsgmbh/faster-whisper-large-v3-turbo) | Установщик скачивает в `models/turbo` |
| Nemotron 3: разметка спикеров | [nvidia/Nemotron-3-Diarization](https://huggingface.co/nvidia/Nemotron-3-Diarization) | Установщик скачивает в кеш Hugging Face; повторная загрузка доступна в «Спикеры» |
| Pyannote: разметка спикеров | [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1) | Примите условия модели на Hugging Face, создайте токен с правом чтения и введите его в «Настройки → Спикеры» |

Обе модели Whisper и Nemotron доступны без личного токена. Для Pyannote
принятие условий и токен обязательны по правилам источника; токен не сохраняется
на GitHub. После скачивания сервис находит модели сам. Немотрон и Pyannote
используют отдельную Python-среду, которую создаёт установщик.

Модели Whisper вместе занимают несколько гигабайт. Зависимости и модели
разметки спикеров требуют дополнительного места. Для первой установки нужен
интернет; после загрузки локальное распознавание работает без него.
Сами веса находятся у авторов моделей: их будущая доступность зависит от них.

## Восстановление ускорения NVIDIA

Обычная установка восстанавливает работу на процессоре. Для скорости прежней
установки нужны драйвер NVIDIA, библиотеки Whisper и GPU-среда разметки спикеров.
Код проверки умеет возвращаться на CPU, если видеокарта недоступна.

### Whisper

1. Установите совместимый [драйвер NVIDIA](https://www.nvidia.com/Download/index.aspx).
2. Скачайте [библиотеки CUDA 12 / cuDNN 9, версия v2](https://github.com/Purfview/whisper-standalone-win/releases/download/libs/cuBLAS.and.cuDNN_CUDA12_win_v2.7z).
   Это версия архива, использованная в исходной рабочей установке.
   SHA-256 архива: `89d396373e2781e01fdd58d35a73aadf9b2dba83d3dcd05a838b9115d50427c3`.
3. Распакуйте архив с помощью 7-Zip. Скопируйте DLL из него в `vendor\cuda\bin`
   внутри папки Whisper. В этой папке должны лежать непосредственно
   `cublas64_12.dll`, `cublasLt64_12.dll`, `cudnn64_9.dll` и остальные `cudnn*_9.dll`.
   Запускатель добавит эту папку в путь поиска библиотек автоматически.
4. Перезапустите сервис и проверьте выбранное устройство в настройках.

Версии CTranslate2 4.8.1 и PyAV 18.0.0 из рабочей установки закреплены
в `requirements.txt`. Требования к CUDA объясняет
[документация faster-whisper](https://github.com/SYSTRAN/faster-whisper#gpu).

### Разметка спикеров

На исходной машине использовался PyTorch `2.11.0+cu126`.
После обычной установки откройте PowerShell в папке Whisper и выполните:

```powershell
py -3.11 -m venv .venv_diarization_gpu
.\.venv_diarization_gpu\Scripts\python.exe -m pip install --index-url https://download.pytorch.org/whl/cu126 torch==2.11.0 torchaudio==2.11.0
.\.venv_diarization_gpu\Scripts\python.exe -m pip install -r requirements-diarization.txt
```

Затем перезапустите сервис. Он отдаёт предпочтение `.venv_diarization_gpu`.
В настройках спикеров проверьте устройство: совместимость зависит от модели
видеокарты и драйвера. Для другой видеокарты может потребоваться другая CUDA-сборка
PyTorch. Если GPU-среда не работает, переименуйте её папку, чтобы сервис вернулся
к `.venv_diarization_cpu`, созданной обычным установщиком.

## Проверка установки без личных записей

`Проверить Whisper.bat` проверяет компоненты. Записи `data/test-ru.wav` в
репозитории нет: пользовательское аудио исключено из копии. Поэтому на чистой
установке замер скорости пропускается с предупреждением, а наличие компонентов
не выдаётся за успешное распознавание. Для настоящей проверки положите короткую
русскую WAV-запись в `data/test-ru.wav` и повторите проверку либо загрузите файл
через интерфейс и убедитесь, что получен текст.

## Что сохраняется и что исключено

Сохраняются `app`, `backend`, `telegram_bot`, `scripts`, `public`, конфигурация
сборки, миграции, тесты, списки зависимостей, BAT-запускатели и документация.
Файл `.openai/hosting.json` содержит только пустые настройки сборки и нужен Vite.

Исключены `data` целиком (проекты, записи, результаты, база, настройки, cookies,
токены Telegram и Hugging Face), `models`, `bundle`, `vendor`, Python-среды,
`node_modules`, собранный интерфейс, логи, PID-файлы и локальные записи разработки.
`Собрать архив для ноутбука.bat` — другой механизм: такой архив может содержать
модели и личные данные, поэтому он также исключён из Git.

После восстановления Telegram и другие личные подключения настраиваются заново.
Пользовательские голосовые образцы, настройки и проекты не восстанавливаются.

## Сохранение следующих рабочих версий

В текущей рабочей папке уже настроен Git и адрес репозитория. Перед экспериментом
откройте терминал в папке Whisper:

```powershell
git status --short
git add .
git diff --cached --stat
git commit -m "Save working version before experiment"
git push
```

Перед коммитом проверьте список файлов: там должен быть код и документация.
`.gitignore` исключает рабочие данные, модели, записи и секреты; не используйте
`git add -f` для этих файлов. Новые файлы с паролями или секретами нельзя класть
в папки исходного кода. Изменения, которые не отправлены через `git push`,
не появятся на GitHub и не переживут потерю диска.
